Photo Gallery — How to add images
=================================

Place your images in this folder using one of these naming patterns:

  1.jpg, 2.jpg, 3.jpg, ... 24.jpg
  or
  1.jpeg, 2.jpeg, ...
  or
  1.png, 2.png, ...
  or
  1.webp, 2.webp, ...

The website will automatically discover and display them in order.
Click any image to open it in a lightbox. Supported formats: JPG, JPEG, PNG, WEBP.
